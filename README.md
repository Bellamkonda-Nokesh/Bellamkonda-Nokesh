## ⟡ What I Do

I sit at the exact crossroads where **software engineering** and **data science** meet. I don't build a frontend in isolation, or run an analysis in a vacuum. I build the **whole product** — the pipeline that collects the data, the backend that processes it, the model that finds meaning in it, and the interface that makes it beautiful.

That's one skill set. Not two separate ones.
